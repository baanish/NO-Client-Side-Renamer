# Nuclear Option Client-Side Renamer v0.1.0

This is the first two-person test build. It maps SteamID64 values to local display aliases and includes an optional Configuration Manager editor for players in the active match.

> **Use this prerelease only for the controlled two-person test.** Vanilla-peer isolation has not passed in either join direction. The modded-host direction is the higher-risk case because the name resolver is process-wide.

## Included

- SteamID64-first alias matching with an exact, case-sensitive name fallback.
- Automatic creation and reload of `BepInEx/config/ClientSideRenamer/aliases.json`.
- Last-known-good retention when an external edit is malformed or invalid.
- A current-match player dropdown with save, remove, and manual reload actions.
- Cache refresh after alias and enable-state changes.
- The private-test `Baanish` to `Baanish | Reaper 5-2` starter mapping.

## Test status

- 22 alias-file tests pass.
- Remote aliases were observed on the tested tactical map, HUD marker, and aircraft MFD.
- Scoreboard, crash, kill, and sink notification aliases were observed on the modded client.
- Vanilla-peer isolation remains untested in both join directions.

Manual testing used Nuclear Option 0.34.2, Steam build 24724372, and BepInEx 5.4.23.4.

## Downloads

- `ClientSideRenamer-v0.1.0-nomm.zip` is the flat package prepared for Nuclear Option Mod Manager.
- `ClientSideRenamer-v0.1.0-plugin-only.zip` can be merged beside `NuclearOption.exe` when BepInEx 5 is already installed.
- `SHA256SUMS.txt` lists both archive checksums.

BepInEx Configuration Manager is optional and is not bundled. Install it separately to use the F1 editor. Direct JSON editing and automatic reload work without it.

The project remains private during this controlled prerelease. NOMM submission will wait for the host-isolation test, removal of the personal starter mapping, and publication of the matching source.
