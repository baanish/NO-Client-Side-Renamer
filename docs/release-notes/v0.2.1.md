# v0.2.1: Steam names in shared CSV rosters

The `SteamID` column now accepts an original Steam display name, such as `baanish`, as well as a canonical SteamID64. Text matches exactly, including capitalization and spaces. CSV quoting works for names containing commas or quotation marks.

Local aliases still take priority. Remote rosters are checked in numbered order, and each roster checks the numeric ID before the name. Duplicate exact names reject the roster. Digit-only identifiers remain reserved for valid SteamID64 values. Text names have the same length and character limits as remote display aliases.

Use an ID when a mapping needs to survive Steam name changes. Name matches can apply to multiple players who use the same name.

All 158 automated tests pass, including exact name matching, ID and roster priority, mixed row limits, and retention after a failed refresh. NuGet vulnerability metadata could not be refreshed. This remains a prerelease for controlled testing. In-game startup, Mono TLS behavior, cache refresh and vanilla-peer isolation still need verification.
