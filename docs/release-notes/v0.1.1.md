# Nuclear Option Client-Side Renamer v0.1.1

This prerelease improves the in-game alias editor for populated servers and removes personal data from the first-run template.

## Changes

- Replaced the unbounded player dropdown with an eight-row, scrollable list.
- Added case-insensitive search by original player name or SteamID64.
- Kept player selection stable across roster changes and duplicate registry entries.
- Replaced the personal starter alias with two disabled, generic examples.
- Recreated a deleted alias file or parent directory from the last valid in-memory document.
- Reported file-watcher binding failures in F1 and the BepInEx log without interrupting the Unity update loop.

## Validation

- 35 automated tests pass.
- Picker tests cover 100-player rosters, search, duplicate IDs, roster changes, and long Unicode names.
- The bounded list and scrollbar were observed in-game with 28 players.
- Earlier two-player testing found no reported runtime issues, but the exact v0.1.1 artifact still needs a short multiplayer smoke test after installation.

## Known limits

- Vanilla-peer isolation is not proven in either join direction. Use this build only for controlled testing.
- Host-local logs, ban-list labels, and local third-party recordings may contain aliases even when vanilla peers do not receive them.
- Text rendered before a reload is not rewritten.
- Spectator coverage in the editor is unverified.

## Packages

- `ClientSideRenamer-v0.1.1-nomm.zip` is the flat package prepared for Nuclear Option Mod Manager.
- `ClientSideRenamer-v0.1.1-plugin-only.zip` can be merged beside `NuclearOption.exe` when BepInEx 5 is already installed.

The public source, tag, and release packages match commit `c35c706`. NOMM submission still waits for the multiplayer isolation gates.
